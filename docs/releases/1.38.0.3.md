# busybox-cosmo 1.38.0.3

基于 BusyBox 1.38.0 与 Cosmopolitan 4.0.2 定制工具链。

## 主要变化

- 增加自有 `bbtty`：查询尺寸、保存状态、进入 raw 模式和恢复状态；修复 Windows
  在 main 前隐式改变 Console 模式与代码页的问题，补齐无副作用和失败回滚测试。
- 完善 Shell 兼容库的工具发现、能力识别、进程与系统信息探测，以及 Windows ARM64
  仿真路径上的测试清理和日志处理。
- 增加固定源码构建的可选伴生工具：zip、xz、zstd、curl 与 CA bundle，提供
  archive/net 分层包、许可和来源记录。
- 修复可信下载受用户 `.curlrc` 中 `insecure` 影响的问题；curl 首参数禁用隐式配置。
  HTTPS 测试直接通过 `bbp_https_get` 验证有效证书、主机名、信任链、有效期和禁止降级。
- 增加 macOS ad-hoc 签名辅助与发布 ZIP 可直接执行的操作说明，强化取源校验及 CI 门禁。

## 下载与边界

- `busybox-cosmo-release.zip`：完整包，包含 bbtty、兼容库、文档和测试。
- `busybox-min.zip`：最小运行包，不等于完整包的全部能力。
- `busybox-archive.zip` / `busybox-net.zip`：可选伴生包，仍按实验交付对待；
  格式与 HTTPS 契约已接入 Unix 矩阵，Windows 伴生工具专项尚未完成。
- macOS ARM64 和 Windows ARM64（x86_64 仿真）仍是实验路径；传统 Console
  测试通过不代表 ConPTY 的输入流、信号和异常恢复已经验收。
- 发行件不承诺 Developer ID 公证。macOS 签名操作见包内 `COMPANION-TOOLS.md`；
  签名会改变文件哈希，应先校验下载完整性。
- 固定版本和 SHA-256 不等于无已知漏洞；双目录源码构建逐位复现也尚未全面验收。
- `lz4/brotli` 仍只保留发现接口，不随包新增。

发布应取自同一提交的成功 CI 产物，并在 GitHub Release 附验证链接与 SHA-256。
